# 외부 서비스

4차 구현: `seoul-subway.ts`는 중계 서버의 `/arrivals`를 호출하고 서울시 응답을 변환합니다.

- 호선 ID로 필터링하고 정보 생성 시각에서 지난 시간을 도착 예정 시간에서 뺍니다.
- 3분 이상 오래되거나 생성 시각이 잘못된 항목은 제외합니다.
- 타임아웃 10초, 화면 이탈 시 취소, API 오류 및 빈 결과 안내를 지원합니다.
- 키 미설정이나 장애 시 실시간 정보 대신 오류 안내를 표시합니다. 예상 시간 알림은 별도로 이용할 수 있습니다.
- 실제 API 키는 `backend/.env`에만 설정합니다. `EXPO_PUBLIC_` 변수에 키를 넣지 않습니다.

설정과 실행: [개발 계획](../../../../docs/development-plan.md).
API 출처: [서울시 실시간 도착정보](https://data.seoul.go.kr/dataList/OA-12764/F/1/datasetView.do).
