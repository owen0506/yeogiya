# 하차 알림

현재 UI는 카운트다운, 1·2·3개 역 전 선택, 전체 화면 하차 안내창을 제공합니다.
웹 화면 내 알림은 권한 대기 없이 시작하고, 브라우저 알림 허용은 별도 버튼에서 요청합니다.
경로 데이터는 서울 주요 구간으로 확장했으며 여전히 **예상 시간 기준**입니다.

5차 구현: 예상 이동 시간 기반 로컬 하차 알림과 10초 체험을 제공합니다.

- `alarm-manager.ts`: 단일 예약, 중복 시작 차단, 취소, 오류 상태, 만료 및 복원.
- `alarm-platform.ts`: Expo Notifications 권한 요청, Android 채널, OS 예약/취소.
- `alarm-platform.web.ts`: 탭 타이머, 허용 시 브라우저 알림, 현재 탭 sessionStorage 복원.
- `use-alarm.ts`: 화면 간 공유 상태 구독. 앱이 다시 활성화되면 절대 시각으로 상태를 보정합니다.
- `alarm-status.tsx`: 홈과 경로 결과에서 기존 알림 확인 및 취소.

기기에서는 예약한 로컬 알림을 OS에 전달합니다. 앱 재실행 시 아직 예약된 알림을 복원합니다.
전원이 꺼졌거나 OS 절전/알림 설정에 따라 알림이 지연·누락될 수 있으며 정확한 시각을 보장하지 않습니다.
네이티브 알림은 개발 빌드/실기기에서 검증해야 합니다.

웹은 탭을 닫으면 타이머가 종료됩니다. 브라우저 알림이 미지원·거부 상태여도 화면 내 알림은 제공합니다.
백그라운드 탭과 절전 환경에서는 타이머가 지연될 수 있습니다.

시간은 데모 노선망 기준이며 실제 탑승 열차 자동 추적, 실시간 재예약, 환승 열차 선택은 구현하지 않았습니다.
사용자가 탑승 후 시작하며 대기·지연 시간은 자동 반영되지 않습니다.
