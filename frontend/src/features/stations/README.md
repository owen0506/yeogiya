# 역 검색과 환승역

`network.ts`의 역 순서·분기를 사용해 `stations.ts`에서 두 종류의 데이터를 만듭니다.

- `stations`: 검색·선택·저장용 통합 역. `id`, `name`, `lines`, `aliases`를 가집니다.
- `stationPlatforms`: 경로 계산 및 실시간 조회용 호선별 항목. `stationId`로 통합 역에 연결됩니다.
- `getStation`: 통합 ID와 기존 호선별 ID를 모두 받아 같은 역 객체를 반환합니다.
- `getStationByName`: 공식 호선별 역명과 이수 별칭을 통합 역으로 연결합니다.
- `stationsOnLine`: 선택한 노선의 역 목록. 순환 접점·지선 접점을 중복 반환하지 않습니다.

금정은 1·4호선, 이수(총신대입구)는 4·7호선으로 표시합니다. 총신대입구, 총신대입구(이수), 이수, 이수(총신대 입구)는 검색 결과 하나를 가리킵니다. 현재 지원 노선에서 동일한 환승역명은 같은 ID를 사용합니다. 다른 노선을 추가할 때는 동명 비환승역을 합치지 않도록 역 식별 기준을 확인해야 합니다.

검색은 부분 이름, 공백 제거, 끝의 `역`, 옛 역명인 당고개·뚝섬유원지를 지원합니다. 입력을 수정하면 이전 선택은 해제됩니다. 같은 통합 역을 출발·도착에 선택하면 경로 찾기를 막습니다.

기존 `mockStations`의 25개 ID는 저장값 호환을 위해 유지합니다. ID는 공식 API 역 코드가 아닙니다.

경로 계산은 호선별 승강장과 환승 시간을 유지합니다. 통합 역에서 시작하거나 끝날 때는 이용 호선을 자동 선택하며, 경로 화면의 `getRouteStops`는 환승역을 한 행으로 표시합니다.

지원 범위와 출처는 [역 데이터 안내](../../../../docs/station-data.md)를 참고하세요.
