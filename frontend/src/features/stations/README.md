# 역 검색

2차 작업 구현 완료. `stations.ts`에 25개 노선별 역 항목과 검색 함수를,
`station-search-field.tsx`에 재사용 가능한 검색·선택 UI를 둡니다.

- 일부 역 이름으로 구성된 UI 개발용 데이터이며 전체 수도권 역 목록이 아닙니다.
- `mock-` ID는 공식 API 역 코드가 아닙니다. 데이터 배열 순서는 경로 연결 순서가 아닙니다.
- 부분 검색, 공백 제거, `강남역`처럼 끝에 역을 붙인 검색을 지원합니다.
- 빈 입력에서는 입력 안내, 일치하는 역이 없으면 빈 결과 안내를 표시합니다.
- 같은 이름의 역은 노선과 고유 ID로 구분합니다.
- 결과를 선택하면 역 객체를 보관하고, 입력을 수정하거나 지우면 선택을 해제합니다.
- 출발·도착 교환 시 입력과 선택 객체를 함께 교환합니다.
- 같은 역 ID를 양쪽에 선택하면 홈 화면에서 안내합니다.

수동 확인: `강남`, `강남역`, `서울역`, `역삼`, `없는역`을 검색하고,
노선 선택, 재입력, 지우기, 출발·도착 교환을 확인합니다.
