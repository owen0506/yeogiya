# 현재 위치 연결용 역 좌표

출발지 또는 도착지의 `내 위치`를 누르면 사용자의 일회성 GPS 좌표와 이 카탈로그를 기기 안에서 비교한다. 반경 3km 안에서 가까운 물리역 최대 3개를 찾고 가장 가까운 역을 기본 연결한다. 사용자는 다른 후보 역을 선택할 수 있다.

이 좌표는 역 위치를 나타내며 출입구나 보행 가능한 경로를 나타내지 않는다. 화면의 거리는 직선거리이고, GPS 길찾기는 역이나 정류장까지의 도보 추정시간을 포함한다. 실제 보행 경로·출입구는 안내하지 않으며, 계산 기준은 [군포 버스 시범 연결](gunpo-bus-pilot.md)에 기록한다. 역과 역 사이의 연결망, 시간표, 실시간 열차 위치 데이터와도 별개다.

## 출처 및 이용 조건

- 자료명: **서울시 역사마스터 정보**, 데이터 ID `OA-21232`
- 제공·저작권: **서울특별시**
- 원문: <https://data.seoul.go.kr/dataList/OA-21232/S/1/datasetView.do>
- 원문 페이지 수정일: **2026-10-02**
- CSV 내려받은 날짜: **2026-10-04**
- 이용 조건: **공공누리 제1유형(출처표시)**. 상업적 이용·변경 가능. <https://www.kogl.or.kr/info/licenseType1.do>
- 원본 파일: `docs/data/seoul-station-master-2026-10-04.csv` (EUC-KR, 784행)
- 배포용 변환 파일: `frontend/src/features/stations/station-locations.json`

서울특별시의 위 자료를 앱의 지원 노선과 역 ID에 연결하고, 부역명 및 과거 역명 표기를 정리해 사용했다. 원본 위도·경도 숫자는 유지했다. 각 좌표에 원본 역사 ID·역사명·호선을 함께 남겼으며 카탈로그의 `source.sha256`에는 원본 CSV의 SHA-256을 기록했다. `.gitattributes`는 이 원본 파일에 한해 줄바꿈 자동 변환을 끄므로 운영체제에 관계없이 내려받은 바이트를 보존한다. 위 수정일은 제공 페이지의 표시 값이며 모든 역의 좌표가 그날 개별 측량되었다는 의미는 아니다.

## 범위와 매칭

현재 앱 연결망에 있는 **1–9호선·신분당선 415개 물리역 모두**에 좌표가 있다. 원본의 호선별·운영기관별 기록을 유지하므로 총 **484개 좌표**이며, 환승역이나 운영기관 중복 기록은 가까운 역을 찾을 때 물리역 ID로 합친다. 수도권 전체 노선 또는 버스 정류장을 지원한다는 뜻은 아니다.

1. 원본 호선을 서비스 노선으로 명시적으로 연결한 다음, 해당 노선의 역 목록에도 존재하는지 확인한다. 예를 들어 경부선·경인선·장항선은 1호선, 과천선·안산선·진접선은 4호선, 별내선은 8호선에 연결한다. 경원선으로 기록된 이촌·왕십리 등은 1호선 역 목록과 일치하지 않아 제외한다.
2. 괄호 안 부역명을 제거하고 기존 앱의 `당고개 → 불암산`, `뚝섬유원지 → 자양`, 총신대입구/이수 표기를 맞춘다. 원본 `지제`는 `평택지제`에 연결한다. 인천1·2호선, 공항철도, GTX 등 지원하지 않는 노선은 같은 역명이 있어도 채택하지 않는다.
3. 회기는 원본에 `역사_ID=1015`, `역사명=회기`, `호선=중앙선`으로만 나타난다. 이 세 값이 일치하는 공식 좌표만 1호선에서도 사용하는 물리역 회기에 명시적으로 연결한다. 중앙선 전체를 추가하는 처리는 하지 않는다.
4. 창동과 까치산은 원본의 4호선·5호선 기록으로 각각 물리역을 찾는다. 누락된 1호선·2호선 승강장의 별도 좌표를 만들어내지 않는다. GPS는 물리역 후보를 찾고, 선택 후 노선 결정은 기존 경로 엔진이 담당한다.
5. 좌표가 없는 역에 추정값을 넣지 않는다. 재생성 때 지원 물리역이 빠지면 기존 카탈로그를 덮어쓰기 전에 실패하므로 새 자료나 연결망 확장 사항을 먼저 검토해야 한다.

금정(1·4호선), 산본, 이수(총신대입구), 어린이대공원, 석남, 회기를 포함해 전체 물리역 집합과 좌표 범위를 테스트로 확인한다. 이름만 맞는 다른 노선이 섞이지 않는지, 환승역이 후보 목록에 중복되지 않는지, 원본을 다시 처리한 결과가 체크인한 카탈로그와 동일한지도 검증한다.

## 재생성

저장소 루트에서 실행한다. 마지막 두 인자는 내려받은 날짜와 원문 페이지 수정일이다. 갱신 자료를 쓸 때는 해당 날짜 및 스냅샷 파일명도 함께 갱신한다.

```powershell
node frontend/scripts/build-station-locations.cjs docs/data/seoul-station-master-2026-10-04.csv 2026-10-04 2026-10-02
```

테스트는 `frontend`에서 실행한다.

```powershell
node --test scripts/test-nearby-stations.cjs
```

생성 스크립트는 저장된 공개 CSV를 읽으며 외부 API 키나 네트워크 요청이 필요 없다. GPS 좌표가 카탈로그에 저장되거나 이 스크립트로 전달되지 않는다.
