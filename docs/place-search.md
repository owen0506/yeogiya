# 장소·주소 검색과 대중교통 연결

역 검색은 기존 역 목록을 사용하고, 장소·주소 검색은 백엔드의 `GET /places/search?query=...`를 통해 카카오 Local API를 호출합니다. `KAKAO_REST_API_KEY` 하나로 키워드 검색과 주소 검색을 사용하며 별도 앱 키나 네이티브 패키지를 추가하지 않습니다. 키를 `EXPO_PUBLIC_*`에 넣지 않습니다.

검색창에서 `세종대학교`, `산본 래미안 하이어스`, 도로명·지번 주소를 입력하고 이름과 주소를 확인한 뒤 후보를 선택합니다. 아파트 단지·건물은 카카오에 등록된 결과가 있는 경우 검색되며 특정 동·호수의 현관 위치를 보장하지 않습니다. 검색 결과는 장소 ID·이름·주소·위도·경도의 공통 모델로 변환합니다. 카카오 API 응답을 교통망의 역·정류장 데이터로 취급하지 않습니다.

## 연결 기준

- 역을 직접 고르면 해당 역에서 시작하거나 끝납니다.
- 장소·GPS 출발은 반경 3km의 가까운 역 최대 3곳과 기존 군포 버스 연결을 비교합니다.
- 장소·GPS 목적지는 반경 3km의 가까운 역 최대 3곳에서 마지막 도보까지 포함해 비교합니다. `역 변경`에서 명시적으로 고른 GPS 연결역은 유지합니다.
- 최단시간은 전체 소요시간, 최소환승은 환승 횟수와 전체 소요시간으로 선택합니다.
- 가까운 장소끼리는 3km 이내의 직접 도보 추정 경로도 비교합니다. 이미 특정 버스를 선택했거나 GPS 연결역을 직접 고른 경우 그 선택을 유지합니다.
- 장소의 이름과 주소는 출발·도착을 바꿔도 유지됩니다. 입력을 수정하거나 지우면 기존 선택이 해제됩니다.
- 선택한 버스로 이후 경로를 다시 계산할 때도 목적지 장소와 마지막 도보를 유지합니다.

장소 검색이 된다고 모든 지역의 대중교통 경로가 지원되는 것은 아닙니다. 지하철은 앱에 포함된 수도권 노선망, 버스는 기존 군포 30·31번 시범 범위만 사용합니다. 도보 시간은 직선거리 기반 추정이며 실제 횡단보도·골목·학교 정문·아파트 출입구를 따라가는 경로를 제공하지 않습니다. 정확한 보행 안내는 별도 보행 경로 데이터 연동이 필요합니다.

## 데이터와 요청

검색어가 2자 이상일 때 잠시 입력을 기다린 뒤 요청하며, 새 입력이나 장소 선택·필드 종료 시 이전 요청을 취소합니다. 로컬 역 후보는 장소 검색 실패와 관계없이 사용할 수 있습니다. 결과가 없거나 연결에 실패하면 검색창에서 상태와 다시 검색할 방법을 안내합니다. GPS 좌표는 기기에서 주변 역·정류장과 비교하며 장소 검색을 위해 외부로 보내지 않습니다.

백엔드 코드를 바꾼 뒤 실행 중인 `node seoul-proxy.mjs`는 재시작해야 새 장소 검색 엔드포인트가 적용됩니다. 프런트엔드는 기존 `EXPO_PUBLIC_SUBWAY_API_BASE_URL`을 사용하므로 키를 다시 발급하거나 새 서버 주소를 설정하지 않습니다.

## 확인

1. 출발역 `금정`과 목적지 장소 `세종대학교`를 골라 마지막 도보의 도착 이름이 학교인지 확인합니다.
2. `산본 래미안 하이어스`를 출발지로 고르고 지하철역을 목적지로 선택합니다.
3. 출발·도착을 바꾸고 장소 이름·주소가 그대로 유지되는지 확인합니다.
4. 주소를 입력하고 주소 후보를 고릅니다. 반경 내 지원 역이 없는 장소는 경로 연결 제한 안내를 확인합니다.
5. 검색 중 글자를 바꾸거나 지우고 이전 결과가 다시 나타나지 않는지 확인합니다.
6. 백엔드 연결을 끊어도 로컬 역 후보를 선택할 수 있는지 확인합니다.
