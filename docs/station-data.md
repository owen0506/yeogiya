# 역 데이터 보완과 환승역 통합

2026-09-21 로컬 수정. 기존 앱에서 제공하던 1~9호선·신분당선의 누락 구간을 보완했습니다. 경의중앙선·수인분당선·공항철도 등 다른 수도권 노선을 추가한 작업은 아닙니다.

## 보완 범위

| 노선 | 보완 구간 |
| --- | --- |
| 1 | 연천–도봉산, 금천구청–신창, 온수–인천, 광명·서동탄 지선 |
| 3 | 대화–지축 |
| 4 | 진접–불암산, 남태령–금정–오이도 |
| 5 | 강일–하남검단산 |
| 7 | 온수–석남 |
| 8 | 별내–암사 |
| 신분당 | 청계산입구–광교 |

지도는 같은 역 순서 데이터에서 본선·지선을 모두 그립니다. 실제 지리적 위치나 거리를 나타내지 않습니다. 2호선 순환과 지선, 6호선 응암 단방향 순환을 포함합니다.

## 환승역 기준

검색·노선도 선택·저장 경로는 물리적인 역 하나를 사용합니다. 금정의 1·4호선, 이수/총신대입구의 4·7호선을 하나로 표시하며, 다른 환승역도 지원 노선의 배지를 함께 표시합니다. 이수의 화면 이름은 `이수(총신대입구)`입니다.

경로 계산은 호선별 승강장을 유지해 환승 5분을 계산하고 화면에서는 같은 환승역의 연속 단계를 합칩니다. 출발·도착역에서 필요하지 않은 환승을 추가하지 않습니다. 기존 호선별 저장 ID도 통합 ID로 읽습니다.

수작업으로 관리하는 앱 내부 데이터입니다. 실시간 운영기관 데이터 자동 동기화, 급행 정차역, 열차별 행선지·배차·대기 시간은 포함하지 않습니다. 역간 2분·환승 5분이라는 기존 예상 시간 기준을 유지합니다.
