# 군포 버스 시범 연결

군포 30번(`GGB225000009`)과 31번(`GGB225000006`)만 우선 연결합니다. 노선·정류장 순서·좌표는 2026-10-06 TAGO 실제 조회로 저장한 `backend/data/gunpo-bus-network.json`을 사용합니다. 버스 도착정보와 차량 위치는 검색·차량 선택 때 다시 조회합니다. 저장한 실시간 테스트 응답을 현재 차량 정보로 사용하지 않습니다.

## 검색 흐름

1. GPS에서 500m 안의 승차 정류장을 찾습니다. 가까운 지원 지하철역 3개까지의 직접 도보 경로도 비교합니다(최대 3km).
   `역 변경`으로 출발 연결 역을 직접 고르면 그 역을 거쳐 가는 경로로 제한합니다. 시범 버스 환승은 금정·산본역만 지원하므로 다른 연결 역을 고른 경우 해당 역까지 직접 도보로 접근합니다.
2. 도보로 정류장에 도착할 시각 이후의 실시간 버스 도착정보를 고릅니다. 이미 지나갈 버스는 제외합니다.
3. TAGO의 정류장 순번이 증가하는 실제 운행 순서로 버스 이동을 계산합니다. 금정·산본역 400m 안의 하차 정류장을 역에 연결합니다.
4. 역까지 도보와 승강장 진입 여유 120초를 더한 **미래 시각**으로 기존 지하철 API를 조회합니다. 첫 열차 대기까지 여정에 포함합니다.
5. 빠른 경로는 최종 도착 시각, 최소 환승은 환승 수 우선으로 비교합니다. GPS 목적지에는 선택한 연결 역에서 마지막 도보 추정시간을 더합니다.

이번 구현은 버스 1회 접근 후보를 비교하고 지하철 탐색 결과와 연결하는 방식입니다. 여러 번의 버스 환승이나 목적지까지 버스만 타는 전체 대중교통 검색은 아직 범위에 포함되지 않습니다. 별도의 공통 Trip/StopTime 시간표 엔진은 유지하며, 실제 운행 시간표가 없는 버스에 가상의 Trip을 만들지 않습니다.

## 시간과 방향의 근거

TAGO 버스 도착정보는 **정류장·노선 기준 ETA**이며 실차 번호와 연결되지 않습니다. 화면에서 특정 차량을 선택한 뒤의 ETA와 남은 소요시간은 그 차량의 노선 정류장 순번과 아래 거리 모델로 다시 추정합니다.

버스 구간 시간은 측정한 평균값이 아닙니다. 직선거리 × 1.3 / 시속 15km + 정차 여유 20초, 최소 45초의 임시 모델을 사용합니다. 도보는 직선거리 / 초속 1.2m이며, GPS 목적지 도보에는 거리 여유 1.25배를 사용합니다. 실제 도로 경로·교통상황·보행 출입구는 반영하지 않습니다. 검증한 구간 시간 데이터가 확보되면 그 값을 먼저 쓰도록 비용 공급자를 분리했습니다.

실제 군포 응답에는 상·하행 코드가 없었습니다. 따라서 노선 ID와 `(정류장 ID, 노선 순번)`으로 정확한 정류장 방문을 구분하며 임의로 반대 방향 간선을 만들지 않습니다. 같은 정류장 ID를 한 노선이 여러 번 방문하면 정류장 ETA만으로 어느 방문인지 확정할 수 없어 해당 지점의 자동 승차 후보를 제외합니다. 차량 위치에서 방문 순번이 확인된 탑승 중 선택은 가능합니다.

## 화면과 차량 선택

`군포 버스도 함께 찾기`를 켜고 군포 정류장 주변에서 `내 위치`로 출발하세요. 지하철 역에서 직접 시작하면 역으로 바로 가는 편이 빨라 버스가 표시되지 않을 수 있습니다. 경로 막대에는 도보·승차 대기·버스·역 환승·지하철의 시간 비율을 표시하며, 일반버스는 초록색을 사용합니다. 메인 색상은 유지합니다.

버스 구간을 눌러 정류장 순서에 표시되는 실제 버스를 선택합니다. `탈 예정`은 원래 승차 정류장 이전 차량, `지금 타고 있어요`는 해당 승차·하차 구간의 차량에만 가능합니다. 선택한 차량으로 남은 시간과 지하철 연결을 다시 계산합니다. 탑승 중 재계산에도 원래 승차 순번·구간 ID를 보존합니다.

버스 위치는 30초마다 조회하고 원래 승차 정류장 8개 전부터 하차 정류장까지 확인합니다. API가 정류장 기준으로 알려주는 위치를 표시하며, 정확한 정류장 사이 위치나 이동 애니메이션을 만들어 내지 않습니다. 하차 알림은 위치와 거리 기반 시간의 추정 알림이며, 이후 지연에 따라 자동 재예약하지 않습니다.

## 오류와 실행

버스 API가 실패하거나 도착정보가 없으면 확인 가능한 후보와 직접 역 도보 경로를 비교합니다. 지하철 시간표 API 실패 시 기존 평균 그래프 경로를 쓰며 지하철 대기시간을 알 수 없다는 문구를 표시합니다. 연결할 경로가 없는 GPS 출발을 도보 시간 없이 역 출발로 바꿔 표시하지 않습니다.

변경한 백엔드를 사용하려면 기존 서버를 종료하고 다시 시작하세요.

```powershell
cd E:\Github_Repository\Yeogiya\backend
$env:HOST = "0.0.0.0"
node seoul-proxy.mjs
```

프런트엔드는 기존과 같이 `frontend`에서 `npx expo start`로 실행합니다. 인증키는 기존 서버 전용 환경변수를 사용하며 `EXPO_PUBLIC_` 변수로 옮기지 않습니다. iPhone은 기존에 설정한 PC의 LAN 주소로 서버에 연결합니다.
