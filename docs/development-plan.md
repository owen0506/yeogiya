# 단계별 개발 계획

| 단계 | 작업 | 상태 |
| --- | --- | --- |
| 1 | 기본 화면 + 폴더 구조 | 구현 완료 |
| 2 | 역 검색 더미 데이터 | 예정 |
| 3 | 경로 결과 화면 | 예정 |
| 4 | 서울시 실시간 API 호출 service 파일 | 예정 |
| 5 | 알림 로직 | 예정 |

## 프런트엔드 구조

- `src/app/`: Expo Router 진입점 및 라우트
- `src/features/journey/`: 이동 입력 화면. 3차에서 경로 결과 화면 추가
- `src/features/stations/`: 2차 역 데이터와 검색 기능
- `src/features/notifications/`: 5차 하차 알림 기능
- `src/services/`: 4차 외부 API 통신
- `src/constants/`, `src/components/`, `src/hooks/`: 기존 공통 상수, 컴포넌트와 훅

1차 화면은 출발·도착역 자유 입력, 입력값 교환, 1개/2개 역 전 알림 시점 선택을 제공합니다.
입력값은 앱 재시작 시 유지되지 않습니다. 검색 버튼은 검색 기능 연결 전까지 비활성화됩니다.
기존 Expo 예제 파일은 보존하되 홈 화면에서는 사용하지 않습니다.

## 실행 및 확인

`frontend`에서 `npm start` 또는 `npm run web`으로 실행합니다.
타입 검사는 `npx tsc --noEmit`으로 실행합니다.

수동 확인: 역 이름 입력, 교환 버튼, 알림 시점 선택, 작은 화면 스크롤과 키보드 표시를 확인합니다.
