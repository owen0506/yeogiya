# 공식 거리·시간표 연동

2026-09-24 기준 서울교통공사 [최단경로이동정보](https://www.data.go.kr/data/15143842/openapi.do)의 `getShtrmPath2`를 사용합니다. 검색할 때마다 현재 한국 시각, 시간표 포함(`schInclYn=Y`) 조건으로 조회합니다. 로컬 노선도의 모양이나 역 목록을 자동 갱신하는 기능은 아닙니다.

- 구간 거리 `stnSctnDstc`는 미터, 운행 시간 `reqHr`와 환승 대기 `wtngHr`는 초입니다. 전체 거리는 API 기준으로 환승 이동도 포함할 수 있습니다.
- 첫 열차 출발부터 마지막 열차 도착까지 계산하므로 중간역 정차와 환승 대기를 포함하고, 첫 열차 탑승 전 대기는 제외합니다.
- 출발·도착 예정 시각, 열차번호·행선지를 표시합니다. 알림은 선택한 시간표의 해당 역 도착 예정 시각을 기준으로 예약합니다. 이미 도착 예정 시각이 지난 경로는 재검색해야 합니다.
- 실시간 지연이나 사용자가 실제로 탄 열차를 자동 추적하지 않습니다. 실시간 도착 조회는 별도 기능이며 이 알림을 보정하지 않습니다.
- API 장애, 누락된 시간표, 미지원 역·노선, 무정차 구간 등 검증되지 않는 응답은 기존 로컬 경로로 대체합니다. 이때 **임시 예상값**임을 표시하고 거리는 표시하지 않습니다. 임시값은 역간 2분·환승 5분입니다.
- 공식 응답의 호선별 금정·이수 역은 앱의 통합 역으로 연결합니다. 환승 시간과 지선 이동은 유지합니다.

`backend/seoul-proxy.mjs`가 키를 서버에서 읽습니다. 앱에는 `EXPO_PUBLIC_SUBWAY_API_BASE_URL=http://localhost:8083`만 공개됩니다. 휴대폰에서는 개발 PC 주소로 변경해야 합니다. 비공개 키를 앱 번들에 넣지 않습니다.

[TAGO 지하철정보](https://www.data.go.kr/data/15098554/openapi.do)는 별도 역·시간표 조회용입니다. 현재 구현은 최단경로 API로 거리와 시간표를 함께 받으므로 TAGO를 중복 호출하지 않습니다.
