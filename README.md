\# 수도권 지하철 하차 알림 앱



수도권 지하철 이용자를 위한 경로 탐색 및 하차 알림 앱입니다.



\## 주요 기능



\- 출발역 / 도착역 입력

\- 추천 경로 표시

\- 실시간 지하철 위치 정보 기반 열차 추적

\- 목적지 도착 전 하차 알림

\- API 실패 시 평균 이동 시간 기반 보정



\## 기술 스택



\### Frontend

\- React Native

\- Expo

\- TypeScript



\### Backend

\- Spring Boot 예정



\### External API

\- 서울시 지하철 실시간 위치정보 API

\- 서울시 지하철 실시간 도착정보 API
