# 여기야 · 서울 지하철 하차 알림

출발역과 내릴 역을 고르고, 탑승 후 예상 시간에 맞춰 하차 알림을 받는 Expo 앱입니다.
웹은 검색 패널과 노선도를 함께 보여주고, 작은 화면은 세로 배치로 전환됩니다.

## 사용 흐름

1. 역 이름을 검색하거나 노선도·역 목록에서 출발역과 도착역을 선택합니다.
2. 빠른 경로 또는 최소 환승을 고르고 이동 구간을 확인합니다.
3. 1·2·3개 역 전 알림 시점을 선택합니다.
4. 실제 탑승 후 **탑승했어요 · 알림 시작**을 누릅니다.
5. 남은 시간을 확인하고, 하차 안내창에서 종료합니다. 10초 체험도 제공합니다.

경로 저장과 최근 검색은 웹의 해당 브라우저에 보관됩니다. 네이티브에서는 현재 앱 세션에만 유지됩니다.
웹 브라우저 알림 권한은 선택 사항이며 화면 내 알림을 시작하는 데 필요하지 않습니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```sh
cd frontend
npm install
npm run web
```

웹 미리보기: `http://localhost:8081`. 휴대폰은 `npm start` 후 Expo 개발 환경에서 실행합니다.

실시간 도착 정보를 조회하려면 [백엔드 설정](backend/README.md)에 따라 개발용 중계 서버를 실행합니다.
인증키는 백엔드 환경 변수에만 설정합니다. 실제 `.env` 파일은 Git 추적에서 제외됩니다.

```sh
cd backend
node --env-file=.env seoul-proxy.mjs
```

## 현재 지원 범위

- 서울 주요 구간의 1~9호선과 신분당선 일부, 300개 이상의 노선별 역 항목.
- 2호선 순환·지선 환승, 6호선 응암 단방향 순환, 노선 간 환승.
- 역간 2분·환승 5분을 가정한 경로 비교와 로컬 알림 예약.
- 서울시 도착 정보 조회 및 조회 실패 시 예상 시간 알림 유지.

수도권 전체 노선, 급행, 시간표, 실제 열차 위치 추적, 열차 지연에 따른 알림 재계산은 지원하지 않습니다.
지도는 실제 좌표가 아닌 간략도이며, 2호선 지도에서 생략한 역과 지선은 역 목록에서 선택합니다.
알림은 실제 도착을 보장하지 않습니다. 현재 역 안내를 함께 확인해야 합니다.
웹 탭을 닫으면 예약 타이머가 종료되고 절전 상태에서는 지연될 수 있습니다.
네이티브의 OS 알림·백그라운드 동작은 실기기에서 추가 검증이 필요합니다.

## 검증

```sh
cd frontend
npm test
npm run typecheck
npx expo export --platform all
```

소스 구조, 구간 범위와 수동 검증 절차는 [프런트엔드 안내](frontend/README.md)를 참고하세요.
